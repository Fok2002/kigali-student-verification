# Kigali Student Verification

## Français

Kigali Student Verification est un service indépendant d'information et d'accompagnement destiné aux parents qui souhaitent se renseigner sur le parcours universitaire de leur enfant à Kigali, au Rwanda.

Le site présente les services, les étapes de traitement d'une demande, les tarifs indicatifs et les moyens de contact. Toute vérification dépend des informations accessibles et des autorisations nécessaires. Le service ne représente pas les universités et ne garantit aucun résultat.

### Utiliser le site

Le site est une page web statique. Pour le consulter localement, ouvrez `kigali_student_verification.html` dans un navigateur. Aucun outil de compilation ni dépendance n'est requis.

Les demandes sont préparées dans le navigateur et proposées à l'utilisateur via WhatsApp. Le formulaire n'enregistre ni ne transmet les réponses à un serveur. L'utilisateur doit vérifier le message puis choisir de l'envoyer dans WhatsApp.

### Fichiers du projet

- `kigali_student_verification.html` — contenu et structure de la page.
- `styles.css` — mise en page et styles adaptatifs.
- `script.js` — préparation du message WhatsApp à partir du formulaire.
- `Pink and Black Modern Initials Logo Design.png` — logo utilisé dans l'en-tête.

Gardez ces fichiers dans le même dossier afin que les liens vers la feuille de style, le script et le logo fonctionnent.

### Confidentialité et limites

Ne demandez ou ne partagez des renseignements personnels qu'avec les autorisations appropriées. Les vérifications sont limitées aux informations pouvant être confirmées de manière fiable et légitime. Le tarif et le périmètre d'une demande doivent être confirmés avant tout paiement.

## English

Kigali Student Verification is an independent information and support service for parents seeking information about their child's university studies in Kigali, Rwanda.

The website describes the services, request process, indicative pricing, and contact options. Any verification depends on available information and the required authorizations. The service is not affiliated with universities and does not guarantee results.

### Using the website

This is a static website. To view it locally, open `kigali_student_verification.html` in a browser. No build tools or dependencies are required.

Requests are prepared in the browser and offered to the user through WhatsApp. The form does not store or send responses to a server. The user can review the message and choose whether to send it in WhatsApp.

### Project files

- `kigali_student_verification.html` — page structure and content.
- `styles.css` — layout and responsive styling.
- `script.js` — prepares a WhatsApp message from the form.
- `Pink and Black Modern Initials Logo Design.png` — logo used in the header.

Keep these files in the same folder so the stylesheet, script, and logo links resolve correctly.

### Privacy and limitations

Request or share personal information only with the appropriate authorization. Verification is limited to information that can be confirmed reliably and lawfully. Confirm the price and scope of a request before making any payment.
